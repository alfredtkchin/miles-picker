KrisFlyer Card Picker - phone app (PWA)

Files: index.html, manifest.webmanifest, sw.js, icon-180/192/512.png
Keep them all in the same folder when you upload.

Host free on GitHub Pages:
1. Create a free account at github.com and a new PUBLIC repository (e.g. miles-picker).
2. Upload all files in this folder (Add file > Upload files) and commit.
3. Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: /(root) > Save.
4. After about a minute your app is at https://YOUR-USERNAME.github.io/miles-picker/

Install on phone:
- iPhone: open the link in Safari > Share > Add to Home Screen.
- Android: open in Chrome > menu (three dots) > Install app / Add to Home screen.

Updating rates later: replace index.html with the new file and commit. Open the app once online; it refreshes itself.
Your added cards are stored on the phone itself (not synced between devices).
